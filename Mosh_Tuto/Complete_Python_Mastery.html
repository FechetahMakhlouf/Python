Getting Started

⏱ 32 min

Welcome to Python! This opening section lays the foundation by explaining what Python is, how to install it, and how to configure your development environment. Think of this as setting up your workshop before building anything. By the end, you'll write and run your very first Python program.

1.1 What is Python?

Python is a high-level, interpreted programming language created by Guido van Rossum in 1991. "High-level" means Python reads almost like English — you don't manage memory or write cryptic machine code. "Interpreted" means your code runs line-by-line through a translator (the Python interpreter) rather than being compiled to a binary first.

Python's design philosophy, summarized in The Zen of Python, values readability and simplicity. This makes it excellent for beginners, data science, web development, automation, machine learning, and scripting.

🧠 Easy to Learn

Minimal punctuation, English-like syntax — less time fighting the language, more time solving problems.

⚡ Dynamic Typing

No need to declare variable types. Python figures them out at runtime automatically.

🌍 Cross-Platform

Runs identically on Windows, macOS, and Linux without modification.

📦 Huge Ecosystem

400,000+ packages on PyPI for web, science, AI, automation, and more.

🔄 Multi-Paradigm

Supports procedural, object-oriented, and functional programming styles.

🤝 Community

One of the largest and most welcoming developer communities in the world.

python
# Python emphasizes readable, clean code
print("Hello, World!")         # A classic first program — outputs text to console
print(2 + 2)                   # Python can evaluate expressions directly
print(type("hello"))           #  — everything in Python is an object
💡
The print() function is your best friend while learning — use it constantly to see what your variables contain and how your code flows.

1.2 Installing Python

Before writing Python code, you need the Python interpreter installed. The installation includes the python executable, the standard library (a rich collection of built-in modules), and pip (the package manager for installing third-party libraries).

Always install Python 3. Python 2 reached end-of-life on January 1, 2020 and receives no security updates. New code should always target Python 3.10 or newer.

⚠️
On Windows, during installation, make sure to check "Add Python to PATH". Without this, the python command won't be found in your terminal.

1.3 Python Interpreter & the REPL

The Python interpreter is the program that reads and executes your code. When you type python in your terminal without a file name, you enter the interactive interpreter — also called the REPL (Read, Eval, Print, Loop). The REPL reads your input, evaluates it, prints the result, and loops back waiting for more.

The REPL is perfect for quick experiments, testing expressions, and exploring APIs without writing a full program. The >>> prompt means Python is ready for your input.

python (REPL)
>>> 2 + 3          # Python immediately evaluates and prints the result
5
>>> print("Hello!")
Hello!
>>> x = 10         # Assigns 10 to x (no output — assignment has no value)
>>> x * 2          # Expressions without print() auto-print in the REPL
20
>>> type(42)       # Check the type of any value
<class 'int'>
>>> help(str)      # Get documentation on any built-in type or function
ℹ️
Use the REPL constantly while learning. Test any concept instantly without creating a file. Press Ctrl+D (Linux/Mac) or Ctrl+Z Enter (Windows) to exit.

1.10 How Python Code is Executed

When you run a .py file, Python performs two steps: it first compiles the source code to bytecode (stored in __pycache__ as .pyc files), then executes the bytecode on the Python Virtual Machine (PVM). You never need to trigger compilation manually — it's transparent.

ℹ️
Bytecode is cached so subsequent runs are faster (no re-compilation if source hasn't changed). The PVM is not the same as a hardware CPU — it's a software interpreter that runs Python bytecode.

Primitive Types

⏱ 34 min

Python's primitive (built-in) types are the fundamental building blocks every program is made of. Understanding how Python stores and manipulates integers, floats, strings, and booleans — and how to convert between them — is essential before tackling more complex concepts.

2.1 Variables

A variable is a named label pointing to a value stored in memory. In Python, you don't declare types — you simply assign a value with =, and Python infers the type automatically. This is called dynamic typing.

Think of a variable not as a box containing a value, but as a sticky note that can be moved from one object to another. Python objects live in memory; variables are just names that reference them.

python
name = "Alice"         # str — text data
age = 25               # int — whole numbers
height = 1.75          # float — decimal numbers
is_student = True      # bool — True or False

# Variables can be reassigned to a DIFFERENT TYPE (dynamic typing)
course = "Python"      # currently a string
course = 42            # now an integer — completely valid!

# Multiple assignment in one line
x = y = z = 0          # x, y, z all equal 0

# Tuple unpacking — swap two values elegantly
a, b = 10, 20
a, b = b, a            # Now a=20, b=10 — no temp variable needed!

# View the type of any variable
print(type(name))      # <class 'str'>
print(type(age))       # <class 'int'>
📝
In Python, everything is an object — including integers, floats, and booleans. Variables don't hold values directly; they hold references to objects in memory.

2.3 Strings

Strings are ordered, immutable sequences of Unicode characters. They can be created with single quotes, double quotes, or triple quotes for multi-line strings. "Immutable" means once a string is created, individual characters cannot be changed — but you can always create new strings derived from existing ones.

Strings support indexing (accessing a single character) and slicing (extracting a substring), both using zero-based integer positions. Negative indices count from the end.

python
msg = "Hello, World!"

# Indexing — access single characters
print(msg[0])          # 'H' — first character (index 0)
print(msg[-1])         # '!' — last character (index -1)
print(msg[7])          # 'W'

# Slicing — syntax: string[start:end:step]
# 'end' index is EXCLUSIVE (not included)
print(msg[0:5])        # 'Hello' — indices 0,1,2,3,4
print(msg[7:])         # 'World!' — from index 7 to end
print(msg[:5])         # 'Hello' — from start to index 4
print(msg[::2])        # 'Hlo ol!' — every other character
print(msg[::-1])       # '!dlroW ,olleH' — reversed string!

# Length
print(len(msg))        # 13

# Concatenation and repetition
greeting = "Hello" + " " + "World"   # concatenation with +
repeated = "ha" * 3                   # 'hahaha'

# Checking membership
print("ello" in msg)   # True — substring check
print("xyz" in msg)    # False
⚠️
Strings are immutable — msg[0] = 'h' raises a TypeError. Instead, create a new string: msg = 'h' + msg[1:].

2.4 Escape Sequences & Raw Strings

Escape sequences let you embed special characters inside strings using a backslash \ prefix. Raw strings (prefixed with r) treat backslashes literally — essential for Windows paths and regular expressions.

python
print("Line 1\nLine 2")           # Two lines
print("Column1\tColumn2")         # Tab-separated
print("C:\\Users\\Alice\\docs")    # Windows path with literal backslashes

# Raw strings — the 'r' prefix ignores ALL escape sequences
print(r"C:\Users\Alice\docs")     # Same result, cleaner to write
print(r"\n is a newline")         # Prints literally: \n is a newline

# Useful for regex patterns
import re
pattern = r"\d{3}-\d{4}"          # Raw string prevents double-backslash hell

2.5 Formatted Strings (f-strings)

f-strings (introduced in Python 3.6) are the most readable and performant way to embed variables and expressions inside strings. Prefix the string with f and place any Python expression inside curly braces {}. The expression is evaluated at runtime and inserted as a string.

f-strings are faster than older approaches like % formatting and .format(), and far more readable. They should be your default choice for string interpolation.

python
first = "Alice"
last = "Smith"
age = 30
gpa = 3.876543

# Basic interpolation
full_name = f"Name: {first} {last}"
print(full_name)            # Name: Alice Smith

# Expressions inside braces — any valid Python expression works
print(f"In 5 years: {age + 5}")      # In 5 years: 35
print(f"Uppercase: {first.upper()}")  # Uppercase: ALICE

# Format specifiers — control number display
print(f"GPA: {gpa:.2f}")             # GPA: 3.88 (2 decimal places)
print(f"Pi: {3.14159:.4f}")          # Pi: 3.1416
print(f"Large: {1000000:,}")         # Large: 1,000,000 (thousands separator)
print(f"Hex: {255:#x}")              # Hex: 0xff
print(f"Percentage: {0.755:.1%}")    # Percentage: 75.5%

# Padding and alignment (useful for tables)
print(f"{'Name':<10} {'Score':>6}")   # Left-align Name, right-align Score
print(f"{'Alice':<10} {95:>6}")
💡
In Python 3.12+, you can use self-documenting expressions: f"{age=}" prints age=30 — great for debugging!

2.6 String Methods

Strings have a rich set of built-in methods. Since strings are immutable, every method returns a new string — the original is unchanged.

python
msg = "  Python Programming  "

# Case methods
print(msg.strip())           # "Python Programming" — removes leading/trailing whitespace
print(msg.strip().lower())   # "python programming"
print(msg.strip().upper())   # "PYTHON PROGRAMMING"
print(msg.strip().title())   # "Python Programming" — capitalize each word

# Search methods
text = "Hello, beautiful World!"
print(text.find("World"))    # 17 — index of first occurrence (-1 if not found)
print(text.count("l"))       # 3 — how many times 'l' appears
print(text.startswith("Hello"))  # True
print(text.endswith("!"))        # True

# Replace and split
print(text.replace("World", "Python"))   # "Hello, beautiful Python!"
words = text.split(", ")                 # Split on ", " → ['Hello', 'beautiful World!']
print(" | ".join(["a", "b", "c"]))      # "a | b | c" — join list into string

# Check content
print("12345".isdigit())     # True — all digits?
print("hello".isalpha())     # True — all letters?
print("  ".isspace())        # True — all whitespace?

2.7 Numbers & Arithmetic

Python has three built-in numeric types: int (arbitrary precision integers), float (double-precision IEEE 754), and complex. Understanding operator precedence (PEMDAS) prevents subtle bugs.

python
import math

# Standard arithmetic
print(10 + 3)     # 13  — addition
print(10 - 3)     # 7   — subtraction
print(10 * 3)     # 30  — multiplication
print(10 / 3)     # 3.333... — ALWAYS returns float in Python 3
print(10 // 3)    # 3   — floor division (rounds DOWN, returns int)
print(10 % 3)     # 1   — modulo (remainder)
print(10 ** 3)    # 1000 — exponentiation (NOT ^, that's XOR)

# Operator precedence (PEMDAS)
print(10 + 3 * 2)    # 16 (multiplication before addition)
print((10 + 3) * 2)  # 26 (parentheses first)

# Augmented assignment
x = 10
x += 3    # x = x + 3 → 13
x *= 2    # x = x * 2 → 26
x //= 3   # x = x // 3 → 8

# Math module — advanced functions
print(round(3.7))         # 4  — built-in, no import needed
print(abs(-42))            # 42 — absolute value
print(math.ceil(3.1))      # 4  — round UP to nearest integer
print(math.floor(3.9))     # 3  — round DOWN to nearest integer
print(math.sqrt(144))      # 12.0
print(math.log(1000, 10))  # 3.0 — log base 10 of 1000
print(math.pi)             # 3.141592653589793
print(math.e)              # 2.718281828459045 (Euler's number)
⚠️
Float arithmetic can be imprecise: 0.1 + 0.2 == 0.3 is False in Python! This is because floats are stored in binary and many decimals can't be represented exactly. Use round() or the decimal module for financial calculations.

2.8 Type Conversion

Python is strongly typed — it won't implicitly convert between types. You must convert explicitly using built-in functions. This often comes up when working with user input from input(), which always returns a string regardless of what the user types.

python
# input() ALWAYS returns a string
birth_year = input("Enter your birth year: ")   # "1998" — a string
age = 2024 - int(birth_year)                    # Must convert to int first
print(f"You are approximately {age} years old")

# Conversion functions
print(int("42"))        # 42     — string to integer
print(int(3.9))         # 3      — float to int (TRUNCATES, doesn't round!)
print(float("3.14"))    # 3.14
print(str(42))          # "42"
print(bool(0))          # False  — 0 is falsy
print(bool(""))         # False  — empty string is falsy
print(bool(None))       # False  — None is falsy
print(bool(1))          # True   — any non-zero number is truthy
print(bool("hello"))    # True   — any non-empty string is truthy

# Falsy values in Python: 0, 0.0, "", [], {}, set(), None, False
# EVERYTHING else is truthy

# Invalid conversions raise ValueError
# int("abc")           # ❌ ValueError: invalid literal for int()
# float("hello")       # ❌ ValueError

Control Flow

⏱ 37 min

Control flow determines the order in which statements execute. Without it, programs run straight through from top to bottom — the same every time. Control flow structures let programs make decisions (if/elif/else), repeat actions (for, while), and respond dynamically to different inputs.

3.1 Comparison Operators

Comparison operators compare two values and always return True or False. They're the foundation of all decision-making. Note that == (equality) is different from = (assignment) — a common beginner mistake.

OperatorMeaningExampleResult
==Equal to5 == 5True
!=Not equal to5 != 3True
>Greater than10 > 3True
<Less than10 < 3False
>=Greater than or equal10 >= 10True
<=Less than or equal5 <= 3False
isSame object in memoryx is Nonedepends
inMembership test"a" in "cat"True
⚠️
Use == to compare values, is to compare identity (same object in memory). Always use is None / is not None when checking for None — never == None.

3.2 Conditional Statements

The if statement evaluates a condition and executes its indented block only if the condition is True. elif (else-if) adds additional branches. else catches everything that didn't match. Only one branch executes — Python stops checking once a true condition is found.

python
score = int(input("Enter your test score (0-100): "))

# Multi-branch grading system
if score >= 90:
    grade = "A"
    msg = "Excellent work!"
elif score >= 80:
    grade = "B"
    msg = "Good job!"
elif score >= 70:
    grade = "C"
    msg = "Decent, keep practicing."
elif score >= 60:
    grade = "D"
    msg = "Needs improvement."
else:
    grade = "F"
    msg = "Please seek tutoring."

print(f"Grade: {grade} — {msg}")

# Nested if — use sparingly (prefer early returns in functions)
age = 25
has_license = True
if age >= 18:
    if has_license:
        print("You can drive")
    else:
        print("Need a license")
else:
    print("Too young to drive")
💡
Order matters! Python checks elif conditions top-to-bottom and stops at the first match. Always put more specific conditions before broader ones.

3.3 Ternary Operator & Logical Operators

The ternary operator condenses a simple if/else assignment into one readable line. Python's and, or, and not let you combine conditions and implement short-circuit logic.

python
# Ternary: value_if_true IF condition ELSE value_if_false
age = 20
status = "adult" if age >= 18 else "minor"   # Clean one-liner

# Logical operators
print(True and False)    # False — both must be True
print(True or False)     # True  — at least one must be True
print(not True)          # False — inverts boolean

# Chained comparisons (Pythonic!)
age = 25
if 18 <= age <= 65:      # Cleaner than: age >= 18 and age <= 65
    print("Working age")

# Short-circuit evaluation: Python stops as soon as the result is certain
# 'and' stops at the first False value
# 'or' stops at the first True value
name = ""
if name and name[0].isupper():  # Safe! Empty string is falsy → stops before [0]
    print("Starts with uppercase")

# Practical: default value pattern using 'or'
user_input = ""
default = user_input or "anonymous"   # "anonymous" if input is empty/falsy
print(default)   # anonymous

3.7 For Loops

A for loop iterates over any iterable (sequences, ranges, strings, lists, files, etc.), executing the loop body once per item. The range() function generates a lazy numeric sequence without storing all numbers in memory.

python
# range(stop) — from 0 to stop-1
for i in range(5):
    print(i)     # 0, 1, 2, 3, 4

# range(start, stop, step)
for i in range(2, 11, 2):
    print(i)     # 2, 4, 6, 8, 10

# Iterate over a string (each character)
for char in "Python":
    print(char)  # P y t h o n (one per line)

# Iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Get both index AND value with enumerate()
for index, fruit in enumerate(fruits, start=1):
    print(f"{index}. {fruit}")   # 1. apple  2. banana  3. cherry

# for...else — else runs only if loop completed without 'break'
for i in range(5):
    if i == 3:
        break
else:
    print("Loop completed normally")   # NOT printed — break was hit

# Nested loops — total iterations = outer × inner
for row in range(3):
    for col in range(4):
        print(f"({row},{col})", end=" ")
    print()  # newline after each row

3.8 While Loops

A while loop runs repeatedly as long as its condition is True. Use it when you don't know in advance how many iterations you need — for example, reading user input until valid, or waiting for a network response.

python
# Wait for valid input
command = ""
while command.lower() != "quit":
    command = input("Enter command (type 'quit' to exit): ")
    if command.lower() != "quit":
        print(f"Running: {command}")
print("Goodbye!")

# Count-controlled while (prefer 'for' when count is known)
count = 0
while count < 5:
    print(count)
    count += 1   # Don't forget to update! Forgetting causes infinite loops.

# break — exit the loop immediately
# continue — skip rest of current iteration, go to next
for i in range(10):
    if i % 2 == 0:
        continue    # skip even numbers
    if i > 7:
        break       # stop when i exceeds 7
    print(i)        # prints: 1, 3, 5, 7
⚠️
Always ensure the while condition will eventually become False, or include a break. An infinite loop (while True: without a break) freezes your program. Use Ctrl+C to stop it.

Functions

⏱ 44 min

Functions are reusable blocks of code that perform a specific task. They're the primary tool for organizing code, avoiding repetition (DRY — Don't Repeat Yourself), and building larger programs from manageable pieces. In Python, functions are first-class objects — they can be stored in variables, passed as arguments, and returned from other functions.

4.1 Defining & Calling Functions

Use def to define a function, followed by a name, parentheses for parameters, and a colon. The indented body is the function's code. Call it by writing its name followed by parentheses.

python
def greet(name):
    """Return a greeting for the given name."""     # Docstring — always include!
    return f"Hello, {name}!"

# Call the function
message = greet("Alice")
print(message)    # Hello, Alice!

# Functions without 'return' implicitly return None
def say_hello():
    print("Hello!")

result = say_hello()   # Prints "Hello!"
print(result)          # None

4.2 Parameters — Positional, Keyword, Default, *args, **kwargs

Python functions support several parameter types, giving you great flexibility in how functions are called.

python
# Default parameters — used when caller doesn't provide the argument
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

print(greet("Alice"))            # Hello, Alice!
print(greet("Bob", "Hi"))        # Hi, Bob!
print(greet("Bob", greeting="Hey"))  # Hey, Bob! — keyword argument

# *args — collect extra POSITIONAL arguments as a tuple
def multiply(*numbers):
    result = 1
    for n in numbers:
        result *= n
    return result

print(multiply(2, 3))         # 6
print(multiply(2, 3, 4, 5))   # 120

# **kwargs — collect extra KEYWORD arguments as a dictionary
def build_profile(**info):
    return info

profile = build_profile(name="Alice", age=30, city="NYC")
print(profile)   # {'name': 'Alice', 'age': 30, 'city': 'NYC'}

# Combining all types (order matters!)
def full_example(pos1, pos2, *args, kw1="default", **kwargs):
    print(pos1, pos2, args, kw1, kwargs)

4.3 Return Values & Scope

A function can return any value (including multiple values as a tuple). Variables inside a function are local — they exist only while the function runs. Variables in the enclosing module are global. Avoid modifying global variables inside functions (use parameters and return values instead).

python
# Multiple return values — Python packs them into a tuple
def min_max(numbers):
    return min(numbers), max(numbers)   # Returns a tuple

lo, hi = min_max([3, 1, 4, 1, 5, 9])   # Unpack directly
print(lo, hi)   # 1 9

# Early return — exit function as soon as result is known
def factorial(n):
    if n < 0:
        raise ValueError("n must be non-negative")
    if n == 0:
        return 1              # Base case
    return n * factorial(n - 1)  # Recursive call

# Scope — local variables don't affect outer scope
message = "Global"

def change():
    message = "Local"     # This is a NEW local variable, not the global!
    print(message)        # Local

change()
print(message)            # Global — unchanged!
ℹ️
Python's scoping follows the LEGB rule: Local → Enclosing → Global → Built-in. Python searches in this order when resolving a name. Use global x or nonlocal x to explicitly modify outer-scope variables (generally not recommended — prefer returning values).

4.7 Debugging in VS Code

Data structures organize related data for efficient access and modification. Python provides powerful built-in structures. Choosing the right one can be the difference between elegant code and a mess of loops — and between fast and slow programs.

5.1 Lists — The Swiss Army Knife

Lists are Python's most-used data structure. They hold ordered collections of any type, support modification, and come packed with useful methods.

python
# Creation

5.2 List Comprehensions, map(), filter(), zip()

List comprehensions are a Pythonic, concise way to create lists. They replace verbose for loops in many cases and are more readable than map() / filter().

python
# List comprehension syntax: [expression for item in iterable if condition]
squares = [x**2 for x in range(10)]          # [0, 1, 4, 9, ..., 81]
evens = [x for x in range(20) if x % 2 == 0] # [0, 2, 4, ..., 18]
pairs = [(x, y) for x in range(3) for y in range(3)]  # 9 pairs

# Lambda — anonymous function defined in one line
double = lambda x: x * 2
print(double(5))   # 10

# map() — apply function to every element
prices = [10, 20, 5]
discounted = list(map(lambda p: p * 0.9, prices))   # [9.0, 18.0, 4.5]
# Same with comprehension (usually preferred):
discounted = [p * 0.9 for p in prices]

# filter() — keep only elements where function returns True
expensive = list(filter(lambda p: p >= 10, prices))  # [10, 20]
# Same with comprehension:
expensive = [p for p in prices if p >= 10]

# zip() — combine multiple iterables element-by-element
names = ["Alice", "Bob", "Charlie"]
scores = [95, 87, 92]
paired = list(zip(names, scores))   # [('Alice', 95), ('Bob', 87), ('Charlie', 92)]
for name, score in zip(names, scores):
    print(f"{name}: {score}")

# Generator expressions — lazy list comprehension (uses () not [])
# Use when the list is large and you only need to iterate once
big_sum = sum(x**2 for x in range(1_000_000))  # Never stores 1M items!
💡
Prefer list comprehensions over map()/filter() for readability. Use generator expressions (with ()) when memory efficiency matters — they generate values on demand rather than storing them all.

5.3 Tuples

Tuples are like lists but immutable — once created, they can't be changed. They're faster than lists, hashable (can be dict keys), and signal to readers that this data should not be modified. Use tuples for fixed records (like coordinates, RGB values, or function return values).

# Use tuple when: data is fixed, or you're returning multiple values from a function

5.4 Sets

Sets store unique, unordered elements. Membership testing is O(1) (instant, regardless of set size) compared to O(n) for lists. They're perfect for deduplication, finding common elements, or checking if something is in a large collection.

python

# Set operations (just like math!)
a = {1, 2, 3, 4}

print(a.issubset({1, 2, 3, 4, 5}))   # True — all of a is in the other set

only_a = event_a - event_b  # {'Charlie'}

stack.append("action3")

6.2 try / except / else / finally

The try block contains code that might fail. If an exception occurs, Python immediately jumps to the matching except block. else runs only if no exception occurred. finally always runs — great for cleanup like closing files or database connections.

python
def safe_divide():
    try:
        # Code that might fail
        x = int(input("Enter numerator: "))
        y = int(input("Enter denominator: "))
        result = x / y

    except ValueError:
        # Handles bad input like "abc" where int() fails
        print("Error: Please enter valid integers.")

    except ZeroDivisionError:
        # Handles division by zero
        print("Error: Cannot divide by zero.")

    except Exception as e:
        # Catch-all for any other unexpected exception
        print(f"Unexpected error: {e}")

    else:
        # Only runs if NO exception was raised in try
        print(f"Result: {result}")

    finally:
        # ALWAYS runs — use for cleanup code
        print("Thank you for using the calculator.")

safe_divide()
⚠️
Avoid catching broad exceptions like except Exception or bare except: unless truly necessary — they hide bugs. Always catch the most specific exception types you expect.

6.5 Raising & Custom Exceptions

Use raise to deliberately trigger an exception — useful for validating inputs and signaling that something is logically wrong. Create custom exception classes by inheriting from Exception to make your code's error messages more descriptive and catchable.

python
# Raising standard exceptions for validation
def set_age(age):
    if not isinstance(age, int):
        raise TypeError("Age must be an integer.")
    if age < 0 or age > 150:
        raise ValueError(f"Age {age} is not realistic.")
    return age

# Custom exception — inherit from Exception (or a more specific base)
class InsufficientFundsError(Exception):
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        super().__init__(
            f"Cannot withdraw ${amount:.2f}. Balance is only ${balance:.2f}."
        )

class BankAccount:
    def __init__(self, balance):
        self.balance = balance

    def withdraw(self, amount):
        if amount > self.balance:
            raise InsufficientFundsError(self.balance, amount)
        self.balance -= amount
        return self.balance

account = BankAccount(100)
try:
    account.withdraw(150)
except InsufficientFundsError as e:
    print(e)   # Cannot withdraw $150.00. Balance is only $100.00.

Classes

⏱ 1h 48min

Object-Oriented Programming (OOP) organizes code around objects — bundles of related data and behavior. A class is a blueprint for creating objects (instances). OOP promotes code reuse via inheritance, encapsulation of complexity, and modeling the real world as interacting objects.

7.1 OOP Concepts

📦 Encapsulation

Bundle data (attributes) and behavior (methods) together. Hide internal details; expose only what's necessary.

🧬 Inheritance

A class can inherit attributes and methods from a parent class, reusing code and building hierarchies.

🎭 Polymorphism

Different objects can respond to the same method call in different ways (e.g., draw() behaves differently for Circle vs Square).

🔒 Abstraction

Hide complex implementation details behind a simple interface. Users interact with high-level methods without knowing the internals.

7.2 Defining Classes & Constructors

The __init__ method (constructor) is called automatically when a new instance is created. self refers to the current instance — it must be the first parameter of every instance method, though you don't pass it explicitly when calling.

python
class Point:
    """Represents a 2D point in space."""

    # Class attribute — shared by ALL instances
    dimensions = 2

    def __init__(self, x=0, y=0):
        """Initialize point with x and y coordinates."""
        self.x = x    # Instance attributes — unique per object
        self.y = y

    def distance_to(self, other):
        """Return Euclidean distance to another point."""
        dx = self.x - other.x
        dy = self.y - other.y
        return (dx**2 + dy**2) ** 0.5

    def __str__(self):
        """Human-readable string representation."""
        return f"Point({self.x}, {self.y})"

    def __repr__(self):
        """Developer-friendly representation (used in REPL)."""
        return f"Point(x={self.x}, y={self.y})"

    def __eq__(self, other):
        """Enable == comparison between points."""
        return self.x == other.x and self.y == other.y

# Creating instances
p1 = Point(3, 4)
p2 = Point(0, 0)

print(p1)                  # Point(3, 4)     — uses __str__
print(p1.distance_to(p2))  # 5.0
print(p1 == Point(3, 4))   # True            — uses __eq__
print(Point.dimensions)    # 2               — class attribute

7.5 Class Methods, Static Methods & Properties

python
class Temperature:
    def __init__(self, celsius=0):
        self._celsius = celsius   # Convention: _ prefix = "private-ish"

    # Property — getter, accessed like an attribute not a method
    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("Below absolute zero!")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9/5 + 32

    # Class method — receives the class (cls) not the instance
    # Use to create alternative constructors
    @classmethod
    def from_fahrenheit(cls, f):
        return cls((f - 32) * 5/9)

    # Static method — no access to instance or class
    # Use for utility functions related to the class
    @staticmethod
    def is_valid(celsius):
        return celsius >= -273.15

t = Temperature(100)
print(t.fahrenheit)              # 212.0
t.celsius = 0
print(t.fahrenheit)              # 32.0

body_temp = Temperature.from_fahrenheit(98.6)
print(body_temp.celsius)         # ~37.0

print(Temperature.is_valid(-300))  # False

7.6 Inheritance & Polymorphism

python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("Subclass must implement speak()")

    def __str__(self):
        return f"{type(self).__name__}(name={self.name})"


class Dog(Animal):
    def speak(self):
        return f"{self.name} says: Woof!"

    def fetch(self, item):
        return f"{self.name} fetches the {item}!"


class Cat(Animal):
    def speak(self):
        return f"{self.name} says: Meow!"


class GuideDog(Dog):
    """Multi-level inheritance — GuideDog → Dog → Animal"""
    def __init__(self, name, owner):
        super().__init__(name)    # Call parent's __init__
        self.owner = owner

    def guide(self):
        return f"{self.name} guides {self.owner} safely."


# Polymorphism — same interface, different behavior
animals = [Dog("Rex"), Cat("Whiskers"), Dog("Buddy")]
for animal in animals:
    print(animal.speak())   # Each responds correctly to speak()

g = GuideDog("Bruno", "Alice")
print(g.speak())    # Bruno says: Woof! — inherited from Dog
print(g.guide())    # Bruno guides Alice safely.

# isinstance — check if object is instance of a class (or its parents)
print(isinstance(g, Dog))     # True
print(isinstance(g, Animal))  # True (GuideDog is also an Animal)

        float: BMI value rounded to 2 decimal places.

    Raises:
        ValueError: If weight_kg or height_m is not positive.

    Examples:
        >>> calculate_bmi(70, 1.75)
        22.86
        >>> calculate_bmi(90, 1.80)
        27.78
    """
    if weight_kg <= 0 or height_m <= 0:
        raise ValueError("Weight and height must be positive.")
    bmi = weight_kg / height_m ** 2
    return round(bmi, 2)

help(calculate_bmi)        # Full docstring in terminal
print(calculate_bmi.__doc__)  # The docstring as a string

Exception Handling Pattern
python
try:
    result = 10 / int(input("Enter number: "))
except ValueError:
    print("Invalid input — not a number")
except ZeroDivisionError:
    print("Cannot divide by zero")
except Exception as e:
    print(f"Unexpected error: {e}")
else:
    print(f"Result: {result}")    # Only runs if NO exception occurred
finally:
    print("Done.")                # ALWAYS runs
